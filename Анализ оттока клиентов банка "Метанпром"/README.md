# Анализ оттока клиентов банка "Метанпром"


## Данные

**В наличии были следующие данные о пользователях:**
- баллы кредитного скоринга,
- город,
- пол,
- возраст,
- количество баллов собственности
- баланс на счёте,
- количество продуктов, которыми пользуется клиент,
- есть ли кредитная карта,
- активный клиент,
- оценочный доход клиента,
- признак оттока. 

## Задача

Выявить закономерности оттока клиентов и какие признаки на это влияют. Произвести сегментацию клиентов банка и приоритизировать сегменты. Дать отделу маркетинга рекомендации о том, на каких клиентов обратить внимание в первую очередь.

## Используемый стек
*pandas*, *numpy*, *matplotlib*, *seaborn*, *scipy*, *sklearn*
