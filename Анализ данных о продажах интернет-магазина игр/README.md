# Анализ данных о продажах интернет-магазина игр


## Данные

**В наличии были следующие данные о пользователях:**
- название игры
- платформа
- год выпуска
- жанр игры
- продажи в Северной Америке (миллионы проданных копий)
- продажи в Европе (миллионы проданных копий)
- продажи в Японии (миллионы проданных копий)
- продажи в других странах (миллионы проданных копий)
- оценка критиков (максимум 100)
- оценка пользователей (максимум 10)
- рейтинг от организации ESRB (англ. Entertainment Software Rating Board). 

## Задача

Выявить закономерности, которые определяют успешность игры, для того, чтобы сделать ставку на потенциально популярный продукт и спланировать рекламные кампании. 

## Используемый стек
*pandas*, *matplotlib*, *seaborn*, *scipy*
