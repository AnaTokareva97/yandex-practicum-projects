# Статистический анализ данных сервиса аренды самокатов GoFast


## Данные

**В наличии были следующие данные о пользователях:**
- Таблица с пользователями:
  - уникальный идентификатор пользователя
  - имя пользователя
  - возраст
  - город
  - тип подписки (free, ultra)

- Таблица с поездками:
  - уникальный идентификатор пользователя
  - расстояние, которое пользователь проехал в текущей сессии (в метрах)
  - продолжительность сессии (в минутах) — время с того момента, как пользователь нажал кнопку «Начать поездку» до момента, как он нажал кнопку «Завершить поездку»
  - дата совершения поездки

- Таблица с информацией о подписке:
  - тип подписки
  - стоимость одной минуты поездки по данной подписке
  - стоимость начала поездки
  - стоимость ежемесячного платежа

## Задача

Исследовать всю имеющуюся информацию о пользователях с подпиской и без. Выяснить какая категория пользователей (подписчики или не подписчики) приносят больше выручки сервису. Помочь отделу маркетинга определить какое минимальное количество промокодов с бесплатной подпиской нужно разослать пользователям, чтобы с вероятностью 95% по итогам акции продлили подписку 10% пользователей. 

## Используемый стек
*pandas*, *numpy*, *matplotlib*, *scipy*, *статистический анализ*
